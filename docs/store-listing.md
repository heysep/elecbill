# 스토어 등록 문구

## 제목 (공백 제외 10자 이내)

```
주거급여 계산기
```

공백 제외 7자. 「주거급여」가 검색어 그대로 앞에 오고, 「계산기」가 무엇을 하는 앱인지 끝낸다.

## 부제 (20자 이내)

```
소득 넣으면 월세 지원액 바로 계산
```

공백 제외 15자.

## 상세설명 (500자 이내)

```
월 소득과 월세만 넣으면 주거급여를 받을 수 있는지, 받는다면 매달 얼마인지 바로 나옵니다.

가구원 수, 사는 곳, 월 소득, 월세, 보증금, 재산을 고르면 화면이 즉시 다시 계산합니다. 버튼을 누르거나 기다릴 필요가 없습니다.

무엇을 보게 되나요
- 우리 집 소득인정액이 기준 중위소득의 몇 퍼센트인지
- 주거급여 자격 여부와 선정기준까지 남은 금액
- 지원액이 나온 과정: 기준임대료, 실제 임차료, 자기부담분
- 같은 소득으로 생계급여, 의료급여, 교육급여도 되는지

2026년 기준과 2027년 기준을 위쪽 버튼으로 바꿔 볼 수 있습니다. 지금 신청하면 2026년 기준이 적용됩니다. 청년 주거급여 분리지급 조건과 신청처도 함께 안내합니다.

보건복지부와 국토교통부 고시 수치를 그대로 넣었습니다. 참고용 모의 계산이며 실제 결정액과 다를 수 있습니다. 입력값은 이 기기에만 저장됩니다.
```
